交互模型总结

🎯 一个快捷键

⇧Z 唤起，不需要记忆多个快捷键。所有功能通过边缘工具栏切换。

🖱️ 框选即截图

松手 = 截图完成，自动复制到剪贴板。不需要点确认按钮，零额外操作。

📐 边缘工具栏

框选过程中浮出，想标注/录屏/翻译/贴图时鼠标移过去选。不点就默认截图。

⚡ 零延迟体验

唤起 <100ms · 复制 <50ms · 冻结画面 · 原生手感 · 无 Web 糊感

✏️ 标注可编辑

矩形、箭头、文字、马赛克等全部可拖拽二次编辑，不是画完就固定。

📌 贴图置顶

截图钉在屏幕上做参考，可拖动、可关闭，支持多贴图同时存在。
