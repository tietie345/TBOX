# 截图录屏翻译标注工具 — 产品方案 V0.3

## 一、产品定位

一款 macOS 桌面效率工具，通过**单一全局快捷键**一键唤起，提供截图、录屏、翻译、标注四大核心能力。对标 iShot / CleanShot X / Snipaste 的体验水准，**先满足个人使用，后续再考虑产品化**。

**核心原则**：体验优先，不计成本。每个环节选"体验最好"的做法，而非"最省事"的方案。

**视觉风格**：参考 iShot，采用白色胶囊工具栏 + 线性图标，专业简洁。

## 二、目标体验

三条铁律：
1. **零延迟唤起** — 按下快捷键到截图遮罩出现 <100ms
2. **原生手感** — 遮罩、放大镜、标注、动画全部跟手，无 Web 页面的"糊"和"飘"
3. **无感权限** — 首次授权引导做到极致，之后用户永远感觉不到权限存在

## 三、核心交互模型

### 统一入口：一个快捷键走天下

```
快捷键 ⌃⇧A → 全屏遮罩冻结画面 → 拖拽框选区域 → 松手进入选区状态（工具栏浮出）→ 点✓复制 / 点✕退出
                                    ├→ 框选过程中右下角白色工具栏浮出
                                    └→ 鼠标移到工具栏点击 = 切换功能
```

- **默认行为就是截图**，松手直接复制，不需要点确认按钮
- 框选**过程中**右下角工具栏实时浮出，想标注/翻译/录屏/贴图时点对应按钮
- 如果只是截图，松手就结束，工具栏自动消失
- **不设独立功能快捷键**，所有功能通过工具栏切换

### 工具栏设计（iShot 风格）

所有浮层控件统一为**白色胶囊**设计：

| 元素 | 规格 |
|------|------|
| 背景 | 白色 `#fff`，圆角 8px，柔和阴影 |
| 图标 | 线性 SVG，1.8px 描边，默认灰色，hover 蓝色 `#2f80ed`，选中蓝底白图标 |
| 尺寸 | 36×32px 按钮，3px 内边距 |

## 四、功能范围

### 4.1 截图
- 全屏、区域、窗口三种模式
- 唤起即全屏冻结画面（截"当前帧"）
- 选区顶部白色信息条：尺寸显示 + 圆角滑块 + 阴影开关
- 四角白色圆形控制点，可拖拽调整选区大小
- 智能窗口/元素识别：鼠标悬停自动蓝色高亮吸附
- 像素级放大镜 + RGB 色值，边缘自动吸附
- 松手即复制到剪贴板（默认行为）
- 支持"贴图钉在屏幕上"（Snipaste 参考功能）

### 4.2 标注
- **8 种标注工具**：矩形、箭头、画笔、文字、马赛克、序号、高亮、模糊
- **全部可拖拽二次编辑**，不是画完就固定
- 双层工具栏：第一行工具，第二行颜色(8色+黑白+自定义)+粗细(3档)
- 颜色/粗细记忆上次选择
- 选中元素显示蓝色控制点，可拖拽/Delete 删除
- 撤销/重做支持
- 智能对齐参考线（拖拽时显示）

### 4.3 录屏（阶段二）
- 区域/窗口/全屏录制
- 顶部深色胶囊控制条（录制指示灯/计时/暂停/画笔/麦克风/停止）
- 系统声音 + 麦克风分轨录制
- 实时键盘按键可视化、鼠标点击波纹高亮
- 录制区域红色虚线边框
- 结束后进入预览，可一键导出 MP4

### 4.4 翻译（阶段二）
- 框选后从工具栏进入
- 系统原生 Vision OCR 识别
- 翻译结果半透明浮层贴回原位置（"给屏幕打字幕"），不弹独立窗口
- 翻译引擎待定（DeepL / OpenAI / 其他）
- 结果可一键复制 / 朗读

### 4.5 贴图
- 截图钉在屏幕最上层，可拖动
- 双击贴图重新进入标注模式编辑
- 右键菜单：关闭 / 复制 / 保存 / 重新标注
- 支持多个贴图同时存在

### 4.6 系统能力
- **单一全局快捷键 `⌃⇧A`**：一个快捷键走天下
- 开机自启（默认开启，可一键关闭）
- 托盘常驻（菜单栏右上角），Dock 无图标
- 独立设置主窗口（从托盘菜单打开，Dock 才显示图标）
- 快捷键冲突检测与提示
- 设置页：通用设置 + 快捷键录制 + （后期）账户/订阅
- **系统日志（os_log）**：关键操作自动记录到系统日志，通过 Console.app 搜索 `TBOX` 即可查看，无需产品自带日志文件

## 五、技术选型

### 主框架：纯原生 Swift + SwiftUI（仅 macOS）

选择理由：
- 截图/录屏/OCR 全部直调系统 API，零中间层，性能最好
- ScreenCaptureKit、CGWindowListCopyWindowInfo 在 Swift 里直接调用
- 个人使用不需要跨平台，原生开发体验最直接
- 标注层用 CAShapeLayer/Core Graphics 实现，性能最优

### 技术栈明细

| 层 | 选型 | 用途 |
|----|------|------|
| 语言 | Swift | 全部逻辑 |
| UI 框架 | SwiftUI + AppKit（混合） | 标注层用 CAShapeLayer，设置页/主窗口用 SwiftUI，遮罩用 NSPanel |
| 截图 | CoreGraphics (CGDisplayCreateImage) | 截图，无权限弹窗 |
| 录屏 | ScreenCaptureKit | 屏幕录制 |
| OCR | Vision Framework | 文字识别 |
| 全局快捷键 | Carbon Event Manager | <10ms 响应 |
| 遮罩面板 | NSPanel (`.nonactivatingPanel`, screenSaver level) | 全屏遮罩 |
| 自启 | SMAppService (macOS 13+) | 开机启动 |
| 托盘 | NSStatusBar | 系统托盘 |
| 贴图 | NSPanel (floating level) | 置顶贴图窗口 |
| 日志 | os.log (Apple Unified Logging) | 关键操作日志，Console.app 可查 |

### 最低系统要求
- macOS 14.0 (Sonoma)，推荐 15.0+

## 六、关键技术难点

### 🔴 卡点1：macOS 系统权限
- 屏幕录制权限：macOS 15+ 会周期性重弹授权提示
- 辅助功能权限（Accessibility）：全局快捷键需要
- 首次引导流程需配图 + 一键跳转系统设置
- 权限没给全时功能灰显 + 说明原因

### 🟡 卡点2：录屏
- 视频编码（H.264）、音画同步、性能、文件体积
- 系统声音录制需虚拟声卡（如 BlackHole）
- 阶段一做完就提前验证录屏性能

### 🟡 卡点3：翻译
- OCR + 翻译串联
- macOS Vision OCR 免费可用
- 翻译结果"贴回原位置"的实用性验证

## 七、用户数据管理

| 数据 | 路径 | 格式 | 说明 |
|------|------|------|------|
| 用户设置 | `~/Library/Application Support/TBOX/config.json` | JSON | 快捷键、格式、颜色记忆 |
| 截图文件 | `~/Pictures/TBOX/screenshots/` | PNG/JPEG | Cmd+S 时保存 |
| 录屏文件 | `~/Movies/TBOX/recordings/` | MP4 | 后期 |
| 标注预设 | `~/Library/Application Support/TBOX/presets/` | JSON | 自定义颜色、粗细组合 |
| 翻译缓存 | `~/Library/Application Support/TBOX/cache.db` | SQLite | 避免重复调 API |

硬原则：
- 所有数据只存本地，不上传服务器
- 截图/录屏默认不保存文件，主动 Cmd+S 才落盘
- 设置用纯 JSON，拷贝即恢复

## 八、开发策略

### 阶段规划

| 阶段 | 周期 | 内容 | 里程碑 |
|------|------|------|--------|
| 准备期 | 第 1-2 周 | Xcode 项目骨架 + Carbon 快捷键 + 权限引导 + OverlayPanel | 按⌃⇧A出遮罩、框选打印坐标 |
| 阶段一 | 第 3-4 周 | 选区裁剪 + 剪贴板复制 + 智能窗口吸附 + 白色胶囊工具栏 + 顶部信息条 | 可替代 Cmd+Shift+4 |
| 阶段二 | 第 5-6 周 | 标注双层工具栏 + 8种标注工具 + 颜色选择器 + 可拖拽编辑 + 贴图 | 完整可用 |
| 阶段三 | 第 7-8 周 | 设置主窗口 + 开机自启 + 快捷键录制 | 个人工具完善 |
| 阶段四 | 第 9-12 周 | 翻译 + 录屏 | 功能完备 |

### 验收硬指标
- 唤起延迟 <100ms
- 复制延迟 <50ms
- Retina 2x 清晰度
- 标注拖拽跟手无延迟

## 九、快捷键

| 操作 | 键位 | 说明 |
|------|------|------|
| 唤起工具 | `⌃⇧A` | 唯一需要记住的全局快捷键（Ctrl+Shift+A，不干扰任何输入） |

## 十、V0.3 → V0.4 变更记录

- **全局快捷键改为 `⌃⇧A`**：原 `⇧Z` 会干扰大写 Z 输入，改用不冲突的组合
- **单击即可框选**：修复首次点击被吞的问题（acceptsFirstMouse）
- **点击选区外围退出**：不再依赖 Esc，点选区外任意位置即可退出截图
- **选区交互优化**：松手进入选区状态（显示工具栏+控制点），不再松手即复制

## 十一、V0.2 → V0.3 变更记录

- **工具栏风格确定**：参考 iShot，采用白色胶囊 + 线性SVG图标，替代原未定风格
- **新增选区顶部信息条**：尺寸+圆角滑块+阴影开关（原设计无）
- **新增四角控制点**：白色圆形蓝边，可拖拽调整选区（原设计无）
- **标注工具栏改为双层**：第一行工具，第二行颜色+粗细属性（原设计单层）
- **标注工具增加**：从6种增加到8种（+画笔/+模糊）
- **框选工具栏按钮扩展**：从4个（标注/录屏/翻译/贴图）扩展到9个（+画笔/+文字/+下载/+✓/+✕）
- **颜色预设扩展**：从6色扩展到8色+黑白+自定义取色
- **新增设计原型**：TBOX-design-prototype.html 可交互原型
- **新增设计决策文档 V0.4**：详细记录所有交互规格
