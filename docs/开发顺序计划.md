# TBOX 开发顺序计划（精简版）

> 更新时间：2026-08-13
> 核心原则：聚焦功能/体验/速度/稳定性，先跑通再优化，拒绝过度设计
> 开发顺序：核心闭环 → 体验增强 → 标注/贴图 → 扩展功能

---

## 开发理念

1. **先能用，再好用，最后好看**
2. **不提前抽象**：先写具体实现，真的需要复用/扩展时再重构
3. **不搞仪式感**：不要为了"架构"写一堆空协议/基类/管理器，直接干
4. **性能优先**：唤起、截图、复制必须快，这是核心体验
5. **减少文件数**：功能简单的直接写在一个文件里，没必要分十几个文件

---

## 开发顺序

### 第一阶段：跑通最小截图闭环

> 目标：按 Shift+Z → 框选 → 松手 → 图片进剪贴板。就这一件事，做到快、稳。

| 序号 | 任务 | 说明 |
|------|------|------|
| 1 | 创建 Xcode 项目 | Swift + AppKit，LSUIElement=YES，Dock 不显示图标 |
| 2 | 托盘图标 | NSStatusBar 一个图标，菜单先只放"退出" |
| 3 | 注册全局快捷键 ⇧Z | Carbon 直接注册，回调能触发就行 |
| 4 | 全屏遮罩 NSPanel | .screenSaver level，覆盖全屏，clearColor 背景 |
| 5 | 按下快捷键时立刻截屏 | SCScreenshotManager.captureImage，缓存 CGImage |
| 6 | 冻结画面 | 截到的图设为遮罩背景，实现"截瞬间帧" |
| 7 | 鼠标拖拽画选区 | 蓝色边框，跟随鼠标，实时更新 rect |
| 8 | 松手裁剪并复制到剪贴板 | 从缓存图按选区裁剪，NSPasteboard 写入 |
| 9 | Esc 关闭遮罩 | 回到空闲状态 |

**验收**：按 Shift+Z 能框选，松手能粘贴，速度够快（<100ms 唤起，<50ms 复制）。这一步做完就已经能替代 Cmd+Shift+4 用了。

**注意**：
- 权限问题遇到再说，第一次跑如果弹权限提示就开，不提前做引导
- 坐标转换（多显示器、HiDPI）这一步必须处理对，这是稳定性核心
- 不要做什么状态机/事件总线，这一步代码直接写在回调里都行

---

### 第二阶段：框选体验增强

> 目标：让框选这件事本身好用，接近 iShot/Snipaste 的手感。

| 序号 | 任务 | 说明 |
|------|------|------|
| 1 | 像素放大镜 | 鼠标旁圆形放大镜，显示十字准星 + RGB 色值 |
| 2 | 选区尺寸显示 | 选区旁边实时显示 W×H，等宽字体 |
| 3 | 窗口智能识别与吸附 | 鼠标悬停窗口时蓝色边框高亮，点击直接选中整个窗口 |
| 4 | 选区四角控制点 | 框选完可以拖控制点调整大小 |
| 5 | 右下角主工具栏（白色胶囊） | 一行平铺：标注/贴图/录屏/翻译/下载/复制/取消 |
| 6 | 工具栏 hover 效果 | 图标变蓝+tooltip，选中蓝底白图标 |
| 7 | 工具栏边界定位 | 选区在屏幕右下角时工具栏自动翻转位置，不溢出屏幕 |
| 8 | 下载保存功能 | 点↓弹出 NSSavePanel，存 PNG |
| 9 | 复制完成反馈 | 简单的视觉提示，告诉用户"已经复制了" |

**注意**：
- 工具栏按钮先做 UI，点击先打桩 print 日志，真正功能后面接
- 颜色先硬编码：白背景、蓝色#2f80ed、图标灰色，不抽 Theme
- 图标直接用 SF Symbols 或者简单画，先不搞 SVG 资源库

---

### 第三阶段：标注功能

> 目标：8种标注工具可用，元素能拖拽编辑，这是最复杂的一块。

| 序号 | 任务 | 说明 |
|------|------|------|
| 1 | 标注画布 | 进入标注模式后，选区变成白底 NSImageView，上面叠 CAShapeLayer 画标注 |
| 2 | 标注双层工具栏 | 选区下方显示：第一行工具按钮，第二行颜色+粗细 |
| 3 | 撤销/重做 | 简单的数组栈，存每一步操作，Cmd+Z/Cmd+Shift+Z |
| 4 | 矩形工具 | 拖拽画矩形，描边，当前颜色+粗细 |
| 5 | 箭头工具 | 拖拽画箭头，三角箭头头 |
| 6 | 自由画笔 | 鼠标移动记录路径，画曲线 |
| 7 | 文字工具 | 点击添加 NSTextField，黄底黑字，可输入可拖动 |
| 8 | 马赛克工具 | 涂抹区域做像素化处理 |
| 9 | 序号标记 | 点击放红底白字圆圈，①②③ 自动递增 |
| 10 | 高亮工具 | 半透明黄色矩形覆盖 |
| 11 | 模糊工具 | 半透明灰色+模糊效果 |
| 12 | 元素选中 | 点击标注元素显示蓝色光晕+控制点 |
| 13 | 元素拖拽/缩放/删除 | 拖动移动，拖控制点改大小，Delete 删除 |
| 14 | 颜色选择器 | 8个颜色圆点+黑白+自定义取色器（直接用系统 NSColorPanel） |
| 15 | 粗细选择 | 3档（细/中/粗） |
| 16 | 标注合成 | 所有标注 layer 渲染到截图 CGImage 上 |
| 17 | 完成/取消 | Enter 合成复制，Cmd+S 合成保存，Esc 取消 |

**注意**：
- 不搞 Shape 基类/形状注册协议，每个形状直接写，重复代码没关系
- 颜色/粗细用 UserDefaults 记一下上次选择就行
- 第二行工具栏只在选中需要颜色的工具时显示，这个逻辑简单写

---

### 第四阶段：贴图功能

> 目标：截图钉在屏幕上，类似 Snipaste。

| 序号 | 任务 | 说明 |
|------|------|------|
| 1 | PinWindow | NSPanel floating 级别，置顶显示截图，白色圆角阴影 |
| 2 | 拖动贴图 | 鼠标拖拽移动位置 |
| 3 | 右键菜单 | 关闭/复制/保存/重新标注 |
| 4 | Esc 关闭 | 选中贴图后按 Esc 关掉 |
| 5 | 双击重新标注 | 双击贴图进入标注模式，标完更新贴图内容 |
| 6 | 工具栏贴图按钮接通 | 点📌直接把截图钉上 |

**注意**：
- 多贴图支持先做简单的，new 一个 PinWindow 就行，不用做管理器
- 不做滚轮缩放、不做分组、不做标签，后期再说

---

### 第五阶段：基础设置

> 目标：有地方能改快捷键，能开机自启，够用就行。

| 序号 | 任务 | 说明 |
|------|------|------|
| 1 | 偏好设置窗口 | 从托盘菜单打开，打开时 Dock 临时显示图标，关掉隐藏 |
| 2 | 通用设置 | 开机自启开关、默认保存格式（PNG/JPG） |
| 3 | 快捷键设置 | 能录制新快捷键，替换默认的 ⇧Z |
| 4 | 开机自启 | SMAppService 实现 |
| 5 | 关于页 | 版本号就行 |

**注意**：
- 不搞深色侧边栏/复杂 UI，SwiftUI 写个简单 Tab 界面就行，能用
- 不做账户/订阅/云端，纯本地工具

---

### 第六阶段：打磨与稳定

> 目标：日常用不崩、不卡、顺手。

| 序号 | 任务 | 说明 |
|------|------|------|
| 1 | 多显示器测试适配 | 不同分辨率/排列/Retina 都要正常 |
| 2 | 全屏 app 兼容性 | 不退出全屏、不抢焦点 |
| 3 | 边界 case 处理 | 选区太小、太靠边、工具栏位置溢出等 |
| 4 | 性能优化 | 标注多了不卡、放大镜流畅、内存及时释放 |
| 5 | 动画细节 | 工具栏淡入淡出、hover 过渡，自然跟手 |
| 6 | 自己日常用，发现 bug 立即修 | 这是最重要的测试方式 |

---

### 第七阶段：录音转写 MVP

> 目标：完成“本地可靠录音 → 会后转写 → 可编辑逐字稿”的基础闭环，并将 AI 会议纪要作为可选增强。  
> 详细依据：[录音转写产品方案](./会议记录产品方案-MVP.md)和[录音转写技术设计](./会议记录技术设计-MVP.md)。

| 序号 | 任务 | 验收重点 |
| --- | --- | --- |
| 1 | 会话模型与本地目录 | JSON 原子写入，索引可重建，schema 可迁移 |
| 2 | 麦克风分段录音 | 独立音轨、权限、输入设备、5 分钟分段 |
| 3 | 系统声音分段录音 | ScreenCaptureKit 音频输出，不依赖视频帧 |
| 4 | 双轨同步与控制条 | 暂停/继续、音量状态、磁盘保护、时间轴正确 |
| 5 | 异常恢复 | 强退后保留已完成分段，启动时发现未完成会话 |
| 6 | ASR 配置与适配器 | Keychain、连接测试、能力声明、Mock 测试 |
| 7 | 分段转写任务 | 持久化进度、有限重试、失败分段续传 |
| 8 | 逐字稿编辑 | 时间戳、正文、说话人改名/合并、点击播放 |
| 9 | 可选 LLM 配置与模板 | 内置模板、自定义模板、Keychain、连接测试 |
| 10 | 可选 AI 纪要生成 | 长文本分块、版本保留、Markdown/TXT 导出 |
| 11 | 长时间稳定性测试 | 2 小时录音、断网、设备拔出、磁盘不足 |

**开发门槛**：录音分段与异常恢复通过验收后，再接入真实 ASR 服务；录音转写通过验收后再接入可选 LLM。任何模型请求不得进入录音关键路径。

### 第八阶段：其他扩展功能（按需加）

> 核心功能稳定后，想加什么加什么。这时候代码结构自然清晰了，真需要复用再重构。

可能的方向：
- 实时会议转写
- 会议软件与日历集成
- 翻译（OCR+翻译）
- 长截图/滚动截图
- 屏幕拾色器（从放大镜扩展）
- GIF 录制
- 贴图滚轮缩放
- 等等...

## 做什么 vs 不做什么

| ✅ 必须做（核心） | ❌ 先不做（冗余） |
|----------------|----------------|
| 快（唤起<100ms，复制<50ms） | 日志系统 |
| 稳（不崩、不错位、多显示器正常） | 复杂权限引导页 |
| 白色胶囊工具栏视觉效果 | 提前抽象协议/基类/插件化架构 |
| 框选手感（跟手、吸附、放大镜） | 事件总线封装 |
| 8种标注+拖拽编辑 | 主题/Design System 抽象 |
| 贴图（钉屏+双击编辑） | 为简单偏好自建 JSON 配置（继续用 UserDefaults） |
| 改快捷键+开机自启 | 复杂的模块管理器/注册表 |
| | 为了"架构美观"拆分一堆小文件 |
| | 账户/订阅/云端同步 |
| | 实时转写/翻译（对应基础闭环完成前不碰） |

## 项目结构（一开始就这么建，简单直接）

```
TBOX/
├── App/
│   ├── AppDelegate.swift        # 入口、托盘、Dock切换
│   └── HotkeyManager.swift      # 全局快捷键
├── Capture/
│   ├── CaptureEngine.swift      # 截图引擎（SCScreenshotManager）
│   └── OverlayPanel.swift       # 全屏遮罩+框选+主工具栏（一开始都写这）
├── Annotation/
│   ├── AnnotationCanvas.swift   # 标注画布+双层工具栏
│   └── Shapes.swift             # 所有标注形状放一个文件里，先不分文件
├── Pin/
│   └── PinWindow.swift          # 贴图窗口
├── Recording/
│   ├── ScreenRecorder.swift     # 普通屏幕录制
│   └── RecordingControlPanel.swift
├── Meeting/
│   ├── Recording/               # 录音转写双轨分段录音
│   ├── Processing/              # 转写与可选 AI 纪要
│   ├── Providers/               # ASR/LLM 适配器
│   ├── Storage/                 # 会话与密钥存储
│   └── UI/                      # 会话列表、逐字稿、AI 纪要
├── Settings/
│   └── SettingsView.swift       # 偏好设置
├── Support/
│   └── Extensions.swift         # 扩展方法、工具函数放一起
└── Resources/
    └── Assets.xcassets          # 图标、图片
```

**结构原则**：截图核心早期保持少文件；录音转写涉及采集、恢复、网络和长期数据，按上述职责分层，避免与普通录屏共用状态机或文件写入链路。
