# TBOX 产品设计决策 V0.4

> 本文档记录基于 V0.2 产品方案的具体交互设计决策，以 iShot 为参考，采用白色胶囊工具栏风格。
> 配套交互原型：[TBOX-design-prototype.html](../TBOX-design-prototype.html)

## 一、应用形态：双形态架构

### 1.1 决策

采用**托盘 app + 独立主窗口**的双形态架构。

| 形态 | 角色 | 行为 |
|------|------|------|
| 托盘 app | 截图主功能 | LSUIElement，托盘常驻，全局快捷键唤起，无 Dock 图标 |
| 独立主窗口 | 设置/账户/订阅 | 托盘菜单打开时 Dock 显示图标，SwiftUI 主窗口 |

### 1.2 技术实现要点

- `Info.plist` 保留 `LSUIElement = true`
- 主窗口默认隐藏，通过托盘菜单「偏好设置」显式唤起
- 主窗口关闭时 app 不退出，仍以托盘形式常驻

## 二、视觉风格：白色胶囊体系

### 2.1 整体风格

参考 iShot 的专业简洁风格，所有浮层控件统一为**白色胶囊**设计：

| 元素 | 风格 |
|------|------|
| 工具栏背景 | 白色 `#fff`，圆角 8px，柔和阴影 `0 4px 24px rgba(0,0,0,0.18)` |
| 图标 | 线性 SVG，1.8px 描边，默认色 `#555`，hover 变 `#2f80ed` |
| 选中态 | 蓝底 `#2f80ed` + 白图标 |
| 分隔线 | 1px `#e8e8e8` |
| 选区边框 | 1.5px 蓝色 `#2f80ed` |
| 选区控制点 | 白色圆形 7px，1.5px 蓝边 |

### 2.2 hover/active 状态

```
默认态：图标 #555，透明背景
hover：图标 #2f80ed，背景 #f0f4ff（淡蓝）
选中(active)：图标 #fff，背景 #2f80ed（蓝色填充）
tooltip：hover 图标上方显示黑色半透明文字标签
```

## 三、框选状态界面

### 3.1 选区顶部信息条

选区上方浮出白色信息条，显示：

| 内容 | 控件 | 说明 |
|------|------|------|
| 尺寸 | 文字 `W × H` | 等宽字体实时显示 |
| 圆角 | 滑块 0-20px | 拖拽调整选区圆角 |
| 圆角值 | 数字 | 实时显示当前圆角值 |
| 阴影 | 复选框 | 勾选则截图带阴影 |

- 信息条白色胶囊背景，跟随选区顶部居中
- 窗口截图时显示窗口名称（如 `🪟 Safari`）替换圆角/阴影

### 3.2 选区右下角主工具栏（一行平铺）

框选过程中，选区右下角外侧浮出白色胶囊工具栏，主功能按钮一行平铺：

| 顺序 | 图标 | 功能 | 说明 |
|------|------|------|------|
| 1 | ✏️ 笔 | 标注 | 进入标注模式 |
| 2 | 画笔 | 手绘 | 自由画笔标注 |
| 3 | T | 文字 | 添加文字 |
| 4 | 🔴 | 录屏 | 录制选区（阶段二） |
| 5 | 🌐 | 翻译 | OCR+翻译（阶段二） |
| 6 | 📌 | 贴图 | 钉在屏幕上 |
| - | \| | 分隔线 | 分隔功能区和操作区 |
| 7 | ↓ | 下载 | 保存到文件 |
| 8 | ✓ | 复制 | 确认复制（蓝色高亮） |
| 9 | ✕ | 取消 | 关闭遮罩 |

**默认行为**：不点任何按钮，松手 = 复制到剪贴板（等同于点 ✓）。

### 3.3 放大镜

- 鼠标旁显示 110px 圆形放大镜，3px 白边
- 十字准星（红色 0.7px）
- 下方显示 RGB 色值

### 3.4 智能窗口吸附

- 鼠标悬停窗口 → 蓝色边框高亮（1.5px `#2f80ed` + 淡蓝填充）
- 选区吸附到窗口边界（虚线边框）
- 顶部信息条显示窗口名称（蓝色文字）
- 点击即选中整个窗口

### 3.5 选区控制点

- 四角：白色 7px 圆点，1.5px 蓝边
- 框选完成后可拖动控制点调整选区大小
- 鼠标样式根据位置变化（nwse-resize / nesw-resize / ns-resize / ew-resize）

## 四、标注模式界面

### 4.1 双层工具栏结构

进入标注模式后，工具栏移至**选区下方居中**，变为**两层白色胶囊堆叠**：

**第一行（工具栏）**：

| 顺序 | 图标 | 功能 | 分组 |
|------|------|------|------|
| 1 | ⬜ | 矩形 | 标注工具 |
| 2 | ↗ | 箭头 | 标注工具 |
| 3 | ✒️ | 画笔 | 标注工具 |
| 4 | T | 文字 | 标注工具 |
| 5 | ▓ | 马赛克 | 标注工具 |
| 6 | ① | 序号 | 标注工具 |
| 7 | 🖍 | 高亮 | 标注工具 |
| 8 | ◎ | 模糊 | 标注工具 |
| - | \| | 分隔线 | |
| 9 | ↩ | 撤销 | 编辑操作 |
| 10 | ↪ | 重做 | 编辑操作 |
| - | \| | 分隔线 | |
| 11 | ↓ | 下载 | 保存文件 |
| 12 | ✓ | 完成 | 确认复制（蓝色） |
| 13 | ✕ | 取消 | 退出标注 |

**第二行（属性栏，选中需要颜色的工具时展开）**：

| 元素 | 说明 |
|------|------|
| 颜色圆点 | 8色预设（红/橙/黄/绿/蓝/紫/粉）+ 白 + 黑 + 自定义取色器（彩色圆盘+号） |
| 分隔线 | 1px 竖线 |
| 粗细选择 | 3档：细(2px) / 中(3.5px) / 粗(6px) |

### 4.2 属性栏显示规则

- **显示第二行**：选中矩形/箭头/画笔/高亮/序号时
- **隐藏第二行**：选中马赛克/模糊/文字时（不需要颜色+粗细，或有独立属性面板）
- 颜色圆点选中态：蓝圈 `#2f80ed` 边框
- 粗细选中态：淡蓝背景 `#edf3ff`

### 4.3 标注元素

| 工具 | 元素样式 |
|------|---------|
| 矩形 | 2.5px 描边，无填充 |
| 箭头 | 2.5px 线条 + 箭头三角 |
| 画笔 | 自由曲线，跟随所选粗细 |
| 文字 | 黄底黑字背景 `rgba(255,235,59,0.92)`，可输入编辑 |
| 马赛克 | 6px 方格图案 |
| 序号 | 红底白字圆形 `#ff3b30`，自动编号 ①②③ |
| 高亮 | 半透明黄色 `rgba(255,200,0,0.35)` |
| 模糊 | 半透明灰 `rgba(100,100,100,0.5)` + backdrop-filter blur |

### 4.4 标注元素交互

- **选中**：蓝色描边 + 蓝色光晕 `0 0 0 1.5px #2f80ed, 0 0 0 3px rgba(47,128,237,0.3)`
- **控制点**：选中元素四角显示白色蓝边控制点（7px），可拖拽调整大小
- **移动**：拖拽元素本体移动位置
- **删除**：选中后按 `Delete`
- **对齐**：拖拽时显示智能对齐参考线

### 4.5 快捷键

| 操作 | 按键 |
|------|------|
| 完成（复制） | `Enter` / 点 ✓ |
| 保存文件 | `⌘S` / 点 ↓ |
| 撤销 | `⌘Z` |
| 重做 | `⇧⌘Z` |
| 删除选中 | `Delete` |
| 取消标注 | `Esc` / 点 ✕ |

## 五、贴图（Pin）窗口

### 5.1 外观

- 白色背景，6px 圆角
- 顶部 20px 标题栏：浅灰 `#fafafa`，显示 📌 图标 + 提示文字
- 柔和阴影 `0 4px 20px rgba(0,0,0,0.3)`
- 1px 细边框

### 5.2 交互

| 操作 | 行为 |
|------|------|
| 拖动 | 鼠标拖拽移动位置 |
| 双击 | 重新进入标注模式，标注完成后更新贴图内容 |
| 右键 | 菜单：关闭 / 复制 / 保存 / 重新标注 |
| Esc | 关闭选中的贴图 |

- 贴图始终置顶（floating window level）
- 支持多个贴图同时存在
- 双击编辑时贴图边框变蓝高亮

## 六、录屏控制条（阶段二）

- 顶部居中胶囊形，深色毛玻璃 `rgba(0,0,0,0.75)` + backdrop-filter
- 录制红点闪烁 + 计时（等宽字体）
- 按钮：暂停 / 画笔 / 麦克风 / 停止（红色圆形）
- 录制区域：红色虚线边框（2px dashed `#ff3b30`）
- 鼠标点击波纹动画

## 七、翻译浮层（阶段二）

- 深色半透明 `rgba(0,0,0,0.85)` 浮层，贴回原文位置
- 显示翻译结果（白色正文）+ 原文（灰色小字）
- 底部操作按钮：复制 / 朗读
- 不弹独立窗口，类似字幕效果

## 八、复制完成反馈

- 屏幕中央闪缩略图预览（200px 宽，蓝色渐变占位）
- 0.6秒后出现绿色 ✓ 覆盖层
- 绿色 toast 提示「✓ 已复制到剪贴板」
- 整体动画 ~1.8 秒淡出，遮罩消失

## 九、设置主窗口

- 左侧边栏（170px）+ 右侧内容区
- 深色主题 `#1e1e30`，侧边栏分区（设置/账户/其他）
- 侧边栏选中项：蓝字 + 蓝底 + 右侧蓝边
- Toggle 开关：蓝色 `#2f80ed`
- 现阶段：通用 + 快捷键两个页面

## 十、状态机

```
Idle ──⇧Z──→ Capturing
                ├─ 松手(不点按钮) ──→ Copying ──→ Idle
                ├─ 点✏️/画笔/T ──→ Annotating ──→ Copying ──→ Idle
                ├─ 点📌 ──→ Pinning ──(双击)──→ Annotating
                ├─ 点🔴 ──→ Recording ──→ Copying ──→ Idle
                ├─ 点🌐 ──→ Translating ──→ Idle
                └─ 点✕/Esc ──→ Idle
```

## 十二、图标资源清单

### 12.1 TBOX 应用图标

已确定采用“屏幕 + 工具箱”方向：蓝色圆角方形底，白色屏幕轮廓与工具箱提手组合，表达截图入口和多功能工具箱定位。

应用图标源文件：[TBOX-app-icon.png](../docs/assets/TBOX-app-icon.png)

工程 AppIcon 资源：`TBOX/TBOX/Assets.xcassets/AppIcon.appiconset/`

所有工具栏图标使用线性 SVG（1.8px stroke-linecap/join: round）：

- 矩形 rect、箭头 arrow、画笔 pen/freehand、文字 text(T)
- 马赛克 mosaic(4格)、序号 number(①)、高亮 highlight
- 模糊 blur(◎)、下载 download(↓)、对勾 check、叉号 close
- 撤销 undo、重做 redo
- 录屏 record(实心圆)、翻译 translate(字符)、贴图 pin(图钉)

## 十三、V0.3 → V0.4 变更记录

| 项 | V0.3 | V0.4 |
|----|------|------|
| 工具栏风格 | 极简图标无背景/深色 | **白色胶囊 + 线性SVG图标**（iShot风格）|
| 主工具栏位置 | 右下角外侧 | **右下角外侧（不变）**，但白色背景 |
| 顶部信息条 | 无 | **新增白色信息条**（尺寸+圆角滑块+阴影）|
| 选区控制点 | 无 | **白色圆形蓝边控制点** |
| 标注工具栏 | 单层水平 | **双层堆叠**（工具行+颜色属性行）|
| 标注工具 | 6种（矩形/箭头/文字/马赛克/高亮/序号） | **8种**（+画笔/+模糊）|

| 参考风格 | CleanShot X | **iShot（白色胶囊+线性图标）** |
