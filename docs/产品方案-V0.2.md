# 截图录屏翻译标注工具 — 产品方案 V0.2（已废弃）

> ⚠️ **本文档已废弃**，请参阅 [产品方案-V0.3.md](./产品方案-V0.3.md)。
> V0.3 更新了视觉风格为iShot白色胶囊工具栏 + 线性图标。

## 一、产品定位

一款 macOS 桌面效率工具，通过**单一全局快捷键**一键唤起，提供截图、录屏、翻译、标注四大核心能力。对标 CleanShot X / Shottr / Snipaste 的体验水准，**先满足个人使用，后续再考虑产品化**。

**核心原则**：体验优先，不计成本。每个环节选"体验最好"的做法，而非"最省事"的方案。

## 二、目标体验

三条铁律：
1. **零延迟唤起** — 按下快捷键到截图遮罩出现 <100ms
2. **原生手感** — 遮罩、放大镜、标注、动画全部跟手，无 Web 页面的"糊"和"飘"
3. **无感权限** — 首次授权引导做到极致，之后用户永远感觉不到权限存在

## 三、核心交互模型

### 统一入口：一个快捷键走天下

```
快捷键 → 框选区域 → 松手 = 截图完成（复制到剪贴板）
                  └→ 框选后鼠标移到边缘工具栏 = 切换功能
```

- **默认行为就是截图**，松手直接复制，不需要点确认按钮
- 框选**过程中**边缘工具栏浮出，用户想标注/翻译/录屏时移过去选
- 如果只是截图，松手就结束，工具栏自动消失
- **不设独立功能快捷键**，所有功能通过边缘工具栏切换

### 边缘工具栏布局（框选后浮出）

| 位置 | 按钮 | 说明 |
|------|------|------|
| 左上 | 标注 | 进入标注模式 |
| 右上 | 录屏 | 录制选区 |
| 左下 | 翻译 | OCR + 翻译 |
| 右下 | 贴图 | 钉在屏幕上 |

中间区域留给截图预览缩略图（松手后闪一下消失，给"截到了"的反馈）。

## 四、功能范围

### 4.1 截图
- 全屏、区域、窗口三种模式
- 唤起即全屏冻结画面（截"当前帧"）
- 智能窗口/元素识别：鼠标悬停自动高亮吸附区域
- 像素级放大镜 + 取色，边缘自动吸附
- 松手即复制到剪贴板（默认行为）
- 支持"贴图钉在屏幕上"（Snipaste 参考功能）

### 4.2 录屏
- 区域/窗口/全屏录制
- 录制中显示轻量控制条（暂停/画笔/停止），不挡内容
- 系统声音 + 麦克风分轨录制
- 实时键盘按键可视化、鼠标点击高亮
- 结束后进入预览，可一键导出 MP4 / 裁剪片段
- ~~GIF 导出~~（技术坑多，优先级低，后期考虑）

### 4.3 翻译
- 截图即翻译（框选后从工具栏进入）
- 系统原生 OCR 识别（macOS Vision Framework）
- 翻译结果悬浮贴回屏幕原位置（"给屏幕打字幕"），不弹独立窗口
- 翻译引擎：待定（DeepL / OpenAI / 其他）
- 支持中英日等主流语言
- 结果可一键复制 / 朗读

### 4.4 标注
- 矩形、箭头、序号标记、马赛克、高亮、文字、放大镜气泡
- **全部可拖拽二次编辑**，不是画完就固定
- 智能对齐参考线
- 颜色/粗细记忆上次选择

### 4.5 系统能力
- **单一全局快捷键**：一个快捷键走天下，框选后通过边缘工具栏切换功能
- 开机自启（默认开启，可一键关闭）
- 托盘常驻
- 快捷键冲突检测与提示

## 五、技术选型

### 主框架：纯原生 Swift + SwiftUI（仅 macOS）

选择理由：
- 截图/录屏/OCR 全部直调系统 API，零中间层，性能最好
- 少一层桥接就快一点，核心卖点就是"快"
- ScreenCaptureKit、CGWindowListCopyWindowInfo 在 Swift 里直接调用
- 个人使用不需要跨平台，原生开发体验更直接

### 技术栈明细

| 层 | 选型 | 用途 |
|----|------|------|
| 语言 | Swift | 全部逻辑 |
| UI 框架 | SwiftUI + AppKit（混合） | 标注层用 Canvas/Core Graphics，设置页用 SwiftUI |
| 截图 | ScreenCaptureKit + CoreGraphics | 截图、窗口识别 |
| 录屏 | ScreenCaptureKit | 屏幕录制 |
| OCR | Vision Framework | 文字识别 |
| 快捷键 | CGEvent / NSEvent | 全局热键 |
| 自启 | SMAppService (macOS 13+) | 开机启动 |
| 托盘 | NSStatusBar | 系统托盘 |

### ~~跨平台~~（已移除）
- V0.2 阶段仅做 macOS，不考虑 Windows 适配
- 后续如需跨平台，再引入 Tauri v2 或其他方案

## 六、关键技术难点（按难度排序）

### 🔴 卡点1：macOS 系统权限
- 屏幕录制权限：macOS 15+ 会周期性重弹授权提示，体验问题无完美解法
- 辅助功能权限（Accessibility）：全局快捷键需要
- 首次引导流程是"用户会不会卸载"的第一道坎，需配图 + 一键跳转系统设置面板
- 权限没给全时功能灰显 + 说明原因，不能点了没反应

### 🟡 卡点2：录屏
- 视频编码（H.264）、音画同步、性能（不能录着卡）、文件体积
- Mac 用 ScreenCaptureKit
- 系统声音录制需虚拟声卡（如 BlackHole）——内置此能力是体验加分项
- 阶段一做完就提前验证录屏性能，别等到最后发现方案扛不住 4K

### 🟡 卡点3：翻译
- 截图翻译需要先 OCR 再翻译
- macOS 自带 Vision OCR 引擎，免费可用
- 翻译结果"贴回原位置"的实用性需快速验证（屏幕内容会变）

### ~~卡点：代码签名与分发~~（已移除）
- 个人本地使用不需要签名和公证
- 后续产品化时再处理

## 七、用户数据管理

### 存储策略

| 数据 | 路径 | 格式 | 说明 |
|------|------|------|------|
| 用户设置 | `~/Library/Application Support/<app>/config.json` | JSON | 快捷键、格式偏好、语言 |
| 截图历史 | `~/Pictures/<app>/screenshots/` | PNG | 按日期分文件夹 |
| 录屏文件 | `~/Movies/<app>/recordings/` | MP4 | 用户选保存位置 |
| 标注预设 | `~/Library/Application Support/<app>/presets/` | JSON | 自定义颜色、粗细、组合 |
| 翻译+OCR缓存 | `~/Library/Application Support/<app>/cache.db` | SQLite | 避免重复调 API |

### 硬原则
- 所有用户数据只存本地，不上传服务器
- 截图/录屏默认不保存到文件，用户主动 Cmd+S 才落盘
- 设置用纯 JSON，重装时拷贝即恢复

## 八、开发策略

### 总体路线
先在自己 Mac 上做出来 → 持续打磨功能和体验 → 稳定后考虑产品化

**原因**：
- 自己做第一个用户，体验判断最快
- 技术验证前置，避免架构返工
- 一个人的团队，不需要评审对齐

### 阶段规划

| 阶段 | 周期 | 内容 |
|------|------|------|
| 准备期 | 第 1-2 周 | 跑通骨架（Swift App + 托盘 + 全局快捷键 + 权限引导空壳） |
| 阶段一 | 第 3-6 周 | 截图 + 智能吸附 + 边缘工具栏 + 标注，做到替换系统自带截图工具 |
| 阶段二 | 第 7-10 周 | 翻译 + 贴图 + 录屏，功能完备，作为个人工具稳定运行 |
| 阶段三 | 待定 | 产品化：代码解耦、签名公证、安装包、分发（如有需要） |

### AI 辅助开发规范

1. **CLAUDE.md 是核心记忆文件**：每次新会话第一句话让 AI 先读它
2. **先验证再集成**：每个新模块先写最小验证脚本，确认 API 调通再往主项目集成
3. **原生 API 不盲信**：AI 对 ScreenCaptureKit 等系统 API 常有"看着对但跑不通"的代码，遇到报错把完整报错 + 上下文甩给 AI
4. **你的价值是体验判断**：不去审查代码，而是亲自用、感受响应速度、标注跟手度、权限流程是否顺畅
5. **做完就记**：每完成一个模块，让 AI 把做了什么、踩了什么坑、API 注意事项写回 CLAUDE.md

## 十二、快捷键设计

### 默认快捷键

- **默认唤醒键**：`⇧Z`（Shift + Z）
- 选择理由：不冲突、好记、单手可按

### 自定义快捷键

- 设置页提供快捷键录制器：点击当前快捷键 → 按新组合键 → 自动保存
- 支持冲突检测：检测到与其他 app 热键冲突时弹提示
- 支持恢复默认

### 快捷键绑定

| 操作 | 默认键 | 说明 |
|------|--------|------|
| 唤醒工具 | `⇧Z` | 唯一需要记住的快捷键 |
| 取消 | `Esc` | 取消当前操作 |
| 保存 | `⌘S` | 保存截图到文件 |
| 复制 | `Enter` | 确认并复制到剪贴板 |
