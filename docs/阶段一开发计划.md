# TBOX 阶段一开发计划

> 创建时间：2026-07-20
> 目标：完成截图 + 标注 + 贴图核心功能，替代系统自带截图工具
 > 周期：约 2 周（AI 辅助开发，全职投入）
> 原计划 6 周，AI 辅助后压缩至 2 周。体验打磨与边界验证不可省略。

## 一、阶段目标

### 1.1 核心交付

一个可日常使用的 macOS 截图工具，满足以下完整流程：

```
Shift+Z 唤起 → 框选区域 → 松手复制到剪贴板
                       └→ 边缘工具栏切换：标注 / 贴图
```

### 1.2 验收标准

| 验收项 | 标准 |
|--------|------|
| 唤起速度 | 按下 Shift+Z 到遮罩出现 <100ms |
| 截图速度 | 松开鼠标到剪贴板写入 <50ms |
| 截图清晰度 | Retina 屏 2x 像素，无模糊 |
| 智能吸附 | 鼠标悬停窗口可自动高亮吸附 |
| 标注功能 | 矩形、箭头、文字、马赛克、高亮、序号标记 |
| 标注编辑 | 所有标注元素可拖拽二次编辑 |
| 贴图功能 | 截图可钉在屏幕上，可拖动、关闭 |
| 开机自启 | 系统启动后自动运行，托盘常驻 |
| 权限引导 | 首次启动有清晰的权限授权引导 |

## 二、周计划分解

### 第 1-2 周：准备期 — 项目骨架与权限

**目标**：跑通最小骨架，验证核心 API 可用性

#### 第 1 周：项目搭建与快捷键

| 任务 | 产出 | 验证方式 |
|------|------|---------|
| 创建 Xcode 项目 | TBOX.xcodeproj 可编译运行 | Cmd+R 能启动 |
| 配置 LSUIElement | app 不在 Dock 显示，仅托盘 | 启动后仅见托盘图标 |
| 实现托盘图标 | NSStatusBar 菜单栏图标 | 点击可退出 |
| 实现 Carbon 全局快捷键 | Shift+Z 触发回调 | 后台任意 app 下按 Shift+Z 有日志输出 |
| 权限检测框架 | PermissionManager 检测辅助功能 | 未授权时弹引导 |

#### 第 2 周：截图引擎与遮罩

| 任务 | 产出 | 验证方式 |
|------|------|---------|
| 屏幕录制权限引导 | 首次截图触发授权流程 | 引导窗口可跳转系统设置 |
| SCScreenshotManager 验证 | 调用 captureImage 获取屏幕图像 | 能拿到 CGImage 并保存为文件 |
| OverlayPanel 实现 | 全屏透明遮罩 panel | panel 能覆盖所有 app（含全屏） |
| 冻结画面 | 截图作为遮罩背景 | 遮罩显示的是按下快捷键瞬间的画面 |
| 鼠标框选 | 拖拽绘制选区框 | 选区框跟随鼠标，实时显示尺寸 |

**准备期里程碑**：按 Shift+Z → 全屏遮罩出现 → 拖拽框选 → 松手后日志打印选区坐标

### 第 3-4 周：截图完成与工具栏

**目标**：截图功能完整可用，可替换系统截图

| 任务 | 产出 | 验证方式 |
|------|------|---------|

| Esc 取消 | 取消截图，关闭遮罩 | 按 Esc 遮罩消失 |
| 放大镜 | 框选时显示像素级放大镜 | 放大镜跟随鼠标，显示像素颜色 |
| 尺寸提示 | 选区旁显示宽×高 | 实时更新 |

#### 第 4 周：智能吸附与边缘工具栏

| 任务 | 产出 | 验证方式 |
|------|------|---------|
| 窗口列表获取 | SCShareableContent 枚举窗口 | 能获取当前所有可见窗口 |
| 窗口高亮 | 鼠标悬停高亮窗口 | 蓝色边框高亮当前窗口 |
| 边缘吸附 | 选区靠近窗口边缘自动对齐 | 拖动到窗口边缘 5px 内吸附 |
| 边缘工具栏 UI | 框选后浮出工具栏 | 四角显示标注/录屏/翻译/贴图按钮 |
| 工具栏交互 | 鼠标移入工具栏可点击 | 点击"标注"进入标注模式 |

**阶段一中里程碑**：完整截图流程可用，松手即复制，可替代系统截图（Cmd+Shift+4）

**阶段一最终里程碑**：完整可用，替换系统截图工具，个人日常使用

## 三、任务优先级与依赖

```
准备期骨架（P0）
  ├── 全局快捷键（P0）→ 无依赖
  ├── 托盘与 LSUIElement（P0）→ 无依赖
  └── 权限引导（P0）→ 依赖快捷键

截图核心（P0）
  ├── SCScreenshotManager（P0）→ 依赖权限
  ├── OverlayPanel（P0）→ 无依赖
  ├── 选区框选（P0）→ 依赖 OverlayPanel
  └── 剪贴板复制（P0）→ 依赖截图

增强体验（P1）
  ├── 放大镜（P1）→ 依赖选区
  ├── 智能吸附（P1）→ 依赖窗口列表
  └── 工具栏 UI（P1）→ 依赖选区

标注功能（P1）
  ├── 画布（P1）→ 依赖工具栏
  ├── 基础形状（P1）→ 依赖画布
  └── 拖拽编辑（P2）→ 依赖基础形状

贴图功能（P2）
  └── PinWindow（P2）→ 依赖截图
```

## 四、风险与应对

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| SCScreenshotManager 首次调用延迟较高 | 中 | 唤起慢于 100ms | 提前预热、遮罩先显示纯色背景 |
| Carbon 快捷键与某些 app 冲突 | 低 | 部分场景失效 | 提供快捷键自定义 |
| 多显示器场景坐标错乱 | 中 | 截图区域偏移 | 第 3 周专门测试多显示器 |
| 标注拖拽性能卡顿 | 低 | 体验下降 | 使用 CAShapeLayer，避免重绘 |
| macOS 权限流程变化 | 低 | 引导失效 | 跟踪系统版本兼容性 |

## 五、验证策略

### 5.1 每周验证

每周末进行一次完整流程验证，记录体验问题：
- 唤起速度是否达标
- 截图是否清晰
- 操作是否跟手
- 边界情况是否处理（多显示器、全屏 app、HiDPI）

### 5.2 日常使用验证

从第 3 周开始，**强制自己用 TBOX 替代系统截图**，记录所有不顺手的地方。

### 5.3 记录与迭代

- 每个模块完成后，更新 CLAUDE.md（API 注意事项、踩坑记录）
- 体验问题记录到 docs/issues.md
- 下周开发前先回顾上周问题
