# TBOX 产品设计决策 V0.3（已废弃）

> ⚠️ **本文档已废弃**，请参阅 [产品设计决策-V0.4.md](./产品设计决策-V0.4.md)。
> V0.4 确定了白色胶囊工具栏 + 线性SVG图标的iShot风格设计。

## 一、应用形态：双形态架构

### 1.1 决策

采用**托盘 app + 独立主窗口**的双形态架构，而非原 V0.2 的纯 LSUIElement 方案。

### 1.2 形态划分

| 形态 | 角色 | 行为 |
|------|------|------|
| 托盘 app | 截图主功能 | LSUIElement，托盘常驻，全局快捷键唤起，无主窗口 |
| 独立主窗口 | 设置/账户/订阅 | Dock 显示图标，SwiftUI 主窗口，托盘菜单可打开 |

### 1.3 技术实现要点

- `Info.plist` 保留 `LSUIElement = true`（默认不显示 Dock 图标）
- 主窗口默认隐藏，用户通过托盘菜单「打开主窗口」显式唤起
- 主窗口关闭时 app 不退出，仍以托盘形式常驻
- 主窗口承载：设置页、账户信息、订阅管理（后期）

### 1.4 优先级

**功能优先**：现阶段先完成截图/标注/贴图核心功能，主窗口仅搭骨架（设置页基础结构），账户/订阅后期填充。

## 二、边缘工具栏（框选后浮出）

### 2.1 决策

| 项 | 决策 |
|----|------|
| 位置 | 选区右下角外侧 8px，实时跟随选区 |
| 出现时机 | 框选过程中实时浮出，不等到松手 |
| 视觉风格 | 极简图标，无背景 |
| hover 交互 | 图标变亮 + 下方显示文字标签 |
| 按钮组 | 标注 / 录屏 / 翻译 / 贴图 |

### 2.2 布局

- 横向排列于选区右下角外侧
- 默认半透明，hover 整组时变亮
- 单个图标 hover：放大 1.1x + 下方显示文字标签（如「标注」「贴图」）

### 2.3 边界处理

- 选区在屏幕右下角时：工具栏自动翻转到选区左下角或上方，避免超出屏幕
- 选区过小（<120px 宽）时：工具栏隐藏，仅松手后显示

### 2.4 交互流程

```
框选中 → 工具栏实时浮出（右下角外侧 8px）
  ├─ 鼠标移入工具栏 → 整组变亮，单个图标可 hover
  ├─ 点击「标注」→ 进入标注模式
  ├─ 点击「贴图」→ 截图钉在屏幕上
  ├─ 点击「翻译」→ OCR + 翻译（阶段二）
  ├─ 点击「录屏」→ 开始录制选区（阶段二）
  └─ 不点工具栏，松手 → 直接复制到剪贴板
```

## 三、标注模式

### 3.1 标注工具栏

| 项 | 决策 |
|----|------|
| 位置 | 选区下方水平排列 |
| 出现时机 | 从边缘工具栏点「标注」后显示 |
| 工具 | 矩形、箭头、文字、马赛克、高亮、序号标记 |
| 颜色/粗细 | 工具栏内联展开 |

### 3.2 颜色/粗细选择器

- 点击当前工具图标 → 下方内联展开颜色圆点 + 粗细滑块
- 颜色圆点：预设 6 色 + 自定义（点「+」打开系统取色器）
- 粗细：3 档预设（细/中/粗）+ 滑块
- 记忆上次选择，下次进入标注模式自动恢复

### 3.3 标注元素

- 全部可拖拽二次编辑（CAShapeLayer 实现）
- 选中后显示控制点，可拖动、删除（Delete 键）
- 智能对齐参考线（拖拽时显示）

### 3.4 标注完成

- `Enter` 或点空白处 → 标注合成到截图，复制到剪贴板
- `Cmd+S` → 合成后保存到文件
- `Esc` → 取消标注，回到截图状态

## 四、贴图（Pin）窗口

### 4.1 决策

| 项 | 决策 |
|----|------|
| 双击行为 | 重新进入标注模式，可继续编辑 |
| 拖动 | 鼠标拖动改变位置 |
| 关闭 | 右键菜单 → 关闭，或 `Esc`（需先点中贴图）|
| 缩放 | 滚轮缩放（可选，后期）|

### 4.2 交互流程

```
贴图常驻屏幕
  ├─ 双击 → 进入标注模式（标注完成后更新贴图内容）
  ├─ 拖动 → 移动贴图位置
  ├─ 右键 → 菜单（关闭 / 复制 / 保存 / 重新标注）
  └─ Esc（选中时）→ 关闭贴图
```

## 五、设置入口

### 5.1 决策

- 托盘菜单提供「打开主窗口」入口
- 主窗口承载设置/账户/订阅，**不**在托盘菜单里直接做设置项
- 现阶段主窗口仅搭骨架：快捷键设置 + 通用设置

### 5.2 主窗口结构（现阶段）

```
主窗口
├── 侧边栏
│   ├── 通用（开机自启、托盘图标）
│   ├── 快捷键（唤醒键录制、冲突检测）
│   └── 关于（版本、开发者）
└── 内容区（根据侧边栏选择切换）
```

### 5.3 主窗口结构（后期）

```
主窗口
├── 侧边栏
│   ├── 通用
│   ├── 快捷键
│   ├── 账户（登录、用户信息）
│   ├── 订阅（套餐、充值、到期）
│   └── 关于
└── 内容区
```

## 六、状态机调整

### 6.1 完整状态机

```
                    ┌─────────────┐
                    │   Idle      │ ← 托盘常驻，监听快捷键
                    └──────┬──────┘
                           │ Shift+Z
                           ▼
                    ┌─────────────┐
                    │  Capturing  │ ← 全屏遮罩，鼠标框选
                    │             │   边缘工具栏实时跟随
                    └──────┬──────┘
                           │ 松开鼠标
                    ┌──────┴──────┐
                    │             │
              默认截图         点击工具栏
                    │             │
                    ▼             ▼
              ┌──────────┐  ┌──────────┐
              │ Copying  │  │Annotating│ ← 进入标注模式
              └────┬─────┘  └────┬─────┘
                   │             │ 完成
                   ▼             ▼
              ┌─────────────────────┐
              │      Finish         │
              │  复制到剪贴板/保存    │
              └─────────┬───────────┘
                        │
                   ┌────┴────┐
                   │         │
                   ▼         ▼
              ┌─────────┐  ┌─────────┐
              │  Idle   │  │ Pinning │ ← 贴图常驻
              └─────────┘  └────┬────┘
                                  │ 双击
                                  ▼
                            ┌──────────┐
                            │Annotating│ ← 重新标注
                            └──────────┘
```

### 6.2 新增状态

- **Pinning**：贴图常驻屏幕，等待用户交互
- **Translating**（阶段二）：OCR + 翻译
- **Recording**（阶段二）：录制选区

### 6.3 状态转换说明

- `Capturing → Copying`：松手且未点工具栏，直接复制
- `Capturing → Annotating`：点「标注」按钮
- `Capturing → Pinning`：点「贴图」按钮，截图直接钉在屏幕
- `Pinning → Annotating`：双击贴图，重新进入标注
- `Annotating → Pinning`：标注完成后可转为贴图
